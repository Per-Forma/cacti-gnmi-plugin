# Cacti gNMI Plugin 1.0.0-beta.1

This is the first public beta of the Cacti gNMI Plugin.

## Highlights

- Persistent, daemon-based gNMI streaming
- Cacti-managed subscriptions, metrics, data sources, and graphs
- Operational health dashboard and event history
- TLS and mutual TLS
- Standard gNMI behavior plus an opt-in Ciena SAOS 10 compatibility mode

## Compatibility

- Cacti 1.2.25 or later; validated through 1.2.31
- PHP 8.1 or later
- Python 3.12 or later

Development used a physical Ciena SAOS 10.8 target. Compatibility validation
also covered Nokia SR Linux 26.3.3 in Containerlab. These are test records, not
vendor support guarantees.

## Beta limitations

- Fresh installations only
- Not recommended for production use
- Other gNMI implementations remain unverified

See `BETA.md`, `docs/install.md`, and `SECURITY.md` before installation.
