# Cacti gNMI Plugin 1.0.0-beta.2

This public beta adds explicit, per-device TLS cipher compatibility without
weakening unrelated gNMI targets.

## Highlights

- Vendor-neutral **TLS Cipher Policy** selector in the device form
- Secure gRPC defaults for existing and newly created devices
- Explicit **Legacy TLS compatibility** policy for targets that require
  `ECDHE-RSA-AES128-SHA`
- Device-scoped daemon environments rather than a container-wide cipher change
- Improved connection-test diagnostics and dashboard visibility
- Bridge diagnostics include the daemon's policy and sanitized last error

Protocol compatibility remains independent. For example, an affected Ciena
SAOS 10 target may require both the Ciena protocol compatibility mode and the
vendor-neutral legacy TLS policy, while another vendor may require only the
TLS policy.

## Security note

Legacy TLS compatibility keeps TLS certificate verification and mutual TLS
active, but permits an older TLS 1.2 CBC/SHA-1 cipher. Enable it only for a
target that cannot negotiate gRPC defaults. Updating the target's TLS profile
to offer modern AEAD ciphers is preferred.

## Compatibility

- Cacti 1.2.25 or later
- PHP 8.1 or later
- Python 3.12 or later

This remains prerelease software. Read `BETA.md`, `docs/install.md`, and
`SECURITY.md` before installation.
