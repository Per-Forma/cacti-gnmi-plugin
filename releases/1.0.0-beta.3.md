# Cacti gNMI Plugin 1.0.0-beta.3

This public beta repairs and hardens AJAX management on the Cacti device page.

## Highlights

- Working subscription and metric add, edit, and delete actions
- Working manual data-source and graph creation and daemon restart actions
- Structured JSON responses for every management request
- Device-scoped target authorization in addition to realm and CSRF checks
- Explicit per-subscription automatic data-source creation setting
- Deployment, package, and Cacti integration checks for runtime dependencies
- Collector shutdown on plugin disable, including CLI plugin management

Subscription topology changes remain asynchronous. The Cacti poller detects
the database change and restarts the affected collector on its next configured
poller cycle.

## Compatibility

- Cacti 1.2.25 or later
- PHP 8.1 or later
- Python 3.12 or later

This remains prerelease software. Read `BETA.md`, `docs/install.md`, and
`SECURITY.md` before installation.

## Release validation

CI installs the generated archive in the pinned Cacti 1.2.31 / PHP 8.5 /
MariaDB 10.6.21 stack and exercises authenticated management and lifecycle
operations. Python 3.12 and 3.14 and PHP 8.1/8.5 syntax remain CI targets.

Publication additionally requires acceptance of the final tagged archive,
browser validation, and a one-hour Nokia SR Linux 26.3.3 soak. The release's
attached acceptance summary records the actual source commit, archive checksum,
runtime versions, outcomes, and any Ciena scenarios not rerun. This section
describes the gate; it does not claim a candidate has passed it.

The wider Cacti and Ciena matrix in the compatibility guide is historical
validation, not a fresh run of every platform against this release.
